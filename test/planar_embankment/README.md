# Planar Embankment SGS Validation Test

Tests SGS sub-cell routing against a standard flow solver on a controlled,
analytically predictable terrain.

## Terrain

```
West (high)                    East (low)
z=4.0 m ─────────────────────── z=0.0 m   (0.1% slope across 4 km)
               │    ▓▓▓▓▓    │
               │    ▓▓ ▓▓    │   ← embankment (2 m tall, 20 m wide)
               │    ▓▓↑▓▓    │      notch: 3 m gap at y=0.5*Ly (centre)
               │    ▓▓▓▓▓    │
Injection ─────┘              └─── downstream domain
(x=10%)           (x=50%)
```

- **Planar slope**: linear gradient 0.1% west→east, total relief 4.0 m.
- **Embankment**: rectangular ridge at x=50%, height 2.0 m above slope, width 20 m.
- **Notch**: 3 m gap at domain centre — narrower than a res-18 A5 cell (~22 m).
- **Injection**: constant inflow at x=10%, y=50%, closed boundaries (no outflow).

## Key elevations

| Feature | Elevation |
|---------|-----------|
| West edge | 4.0 m |
| East edge | 0.0 m |
| Embankment crest | ~4.0 − 0.001×2000 + 2.0 = **4.0 m** (at x=2000 m) |
| Notch sill | ~2.0 m (natural slope at embankment position) |
| Injection cell | ~3.6 m (at x=400 m) |

The embankment crest and notch sill differ by 2.0 m — the embankment height.
SGS detects the notch and routes water at notch sill WSE; standard flow waits
until WSE exceeds the embankment crest.

## Test assertions

| Test | Description |
|------|-------------|
| T0 | Both meshes have cells on both sides of the embankment |
| T1 | Standard flow: no downstream water while upstream WSE < crest |
| T2 | SGS: downstream water appears once WSE ≥ notch sill (well before crest) |
| T3 | SGS routes more water downstream than standard at same injection history |
| T4 | Mass balance < 0.01% for both solvers (closed domain) |
| T5 | HDF5 output files valid: correct frame count, non-zero depths |

## Quick start

```powershell
# 1. Generate DEM (once)
python test/planar_embankment/generate_planar_embankment_dem.py

# 2. Run tests (meshes auto-generated if absent — takes 2-5 min first time)
julia --threads auto test/planar_embankment/test_planar_embankment.jl

# 3. Optional: run with Makie visualisation (standard flow T5 only)
julia --threads auto test/planar_embankment/test_planar_embankment.jl --vis
```

VS Code launch configs: `[PE-00]` through `[PE-06]`.

## Customisation

```powershell
# Steeper slope (1%)
python test/planar_embankment/generate_planar_embankment_dem.py --slope-pct 1.0

# Taller embankment
python test/planar_embankment/generate_planar_embankment_dem.py --emb-height 3.0

# Wider notch (still sub-cell at res 18)
python test/planar_embankment/generate_planar_embankment_dem.py --notch-width 10.0
```

After changing DEM parameters, delete the mesh parquet files before re-running.
