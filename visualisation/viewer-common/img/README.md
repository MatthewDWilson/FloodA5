# Images of the globe viewers

- `GoogleMaps_Logo_WithDarkOutline.svg` — the Google Maps logo, from Google's
  *Google Maps attribution assets* (developers.google.com/maps/documentation/tile/policies,
  `Google_Maps_Attribution_Assets.zip`, July 2025), unmodified. Shown, as the
  Map Tiles API policies require, in the Giro3D viewer's credits while the
  Google Photorealistic 3D Tiles are displayed (CesiumJS shows its own). The
  outlined variant is the one for busy backgrounds such as a map. Google's
  trademark: use only for that attribution.
